# FixPrint
Windows operatsion tizimida printerlar bilan bog'liq eng ko'p tarqalgan muammolarni avtomatik tarzda hal qilishga qaratilgan skript.

## Xususiyatlari
- Tarmoqdagi printerlarga ulanishdagi xatoliklar (PrintNightmare, 0x0000011b) ni to'g'rilash.
- Qotib qolgan printer navbatini (Stuck Print Queue) tozalash.
- Print xizmatining ishlashi uchun zarur bo'lgan asosiy reyestr kalitlari va provayderlarni tiklash.
- Printerlar holatini avtomatik diagnostika qilish.

## Ishlatilishi
Dasturdan foydalanish juda oson. `FixPrint.exe` faylini ishga tushiring (avtomatik ravishda administrator huquqi so'raladi). Grafik interfeys (GUI) orqali "Scriptni o'rnatish" tugmasini bosing va kompyuterni qayta ishga tushiring.
